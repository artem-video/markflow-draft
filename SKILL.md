# MarkFlow Draft: черновик говорящей головы для Premiere Pro

Бесплатная часть MarkFlow (artemsytnik.com/markflow). Работу делает скрипт `scripts/markflow_cut.py`
из папки этого скилла (Python 3, только стандартная библиотека): сверяет слова расшифровки со сценарием
по правилам, без нейросети. Твоя часть — собрать вход, запустить скрипт, отдать файлы и коротко объяснить,
что делать дальше. Скилл работает в любой нейросети, которая умеет запускать код. Если тебе дали zip, сначала
распакуй его. Если запускать код ты не можешь, честно скажи об этом и предложи включить выполнение кода
или открыть Claude или ChatGPT.

Отвечай на языке пользователя, коротко, без технических подробностей: пользователь — монтажёр.

## 1. Собрать вход

Нужно:

1. **Расшифровка записи в SRT.** Если её нет, объясни, как получить в Premiere Pro:
   - правый клик по исходнику → «Новая секвенция из клипа» (клип с начала, без подрезки);
   - окно «Текст» → «Расшифровать последовательность»;
   - там же «Создать субтитры», потом в меню «···» вкладки «Субтитры» → «Экспорт в SRT».
   Подойдёт и JSON со словами и таймингами (Whisper и подобные) — тогда передай его через `--words`.
   Время в расшифровке должно совпадать со временем исходника. Если секвенция начинается не с начала
   клипа, черновик съедет: попроси сделать расшифровку заново, как выше.
2. **Сценарий** (по желанию, но с ним точнее). Текстом в чат, `.txt`, `.md` или `.docx`.
   Сохрани в `script.txt` **только то, что ведущий говорит в кадр**: убери ссылки, ремарки, пометки
   «ЛАЙВ», «ВСТАВКА», таймкоды, имена спикеров, текст чужих синхронов. Если сценарий — таблица с колонками
   вроде «СЪЕМКА | ТЕКСТ | ВСТАВКИ», бери только колонку текста в строках ведущего (СТУДИЯ, СТЕНДАП и т. п.).
   Без сценария скрипт убирает только явные повторы и фальстарты.
3. **Исходное видео:** имя файла (лучше полный путь — тогда Premiere сам найдёт видео), частота кадров
   секвенции (по умолчанию 25), разрешение секвенции (по умолчанию 1920×1080) и разрешение исходника,
   если оно другое (например, 4K: `--source-width 3840 --source-height 2160` — кадр впишется в секвенцию).
   Если пользователь не знает, бери значения по умолчанию.

Если чего-то не хватает, спроси одним сообщением, не по одному вопросу.

## 2. Запустить

```bash
python scripts/markflow_cut.py --srt raw.srt --script script.txt --media "Имя файла.mp4" \
  --fps 25 --width 1920 --height 1080 --out "<название>_черновик"
```

- Без сценария — не передавай `--script`.
- Паузы: `--pause 0.5` (по умолчанию). «Паузы длинные» → `0.35`, «режет слишком плотно» → `0.8`.
- Скрипт печатает одну строку JSON: длина записи и черновика в минутах, число кусков, сколько фраз
  сценария нашлось. Длинные выводы в чат не вставляй.
- Скрипт отправляет анонимную статистику запуска (режим, минуты, число кусков; без текста, имён и файлов)
  на artemsytnik.com, чтобы автор видел, что скиллом пользуются. Если пользователь против, добавь `--no-ping`.
  Если спросят, расскажи об этом честно.

## 3. Отдать результат

Отдай файлы:
- `<название>_черновик.xml` — главная. Premiere: **Файл → Импорт** → выбрать XML. Появится секвенция
  «MarkFlow черновик». Если Premiere спросит, где видео, — указать исходный файл.
- `<название>_черновик.edl` — запасной вариант, если XML не открылся: **Файл → Импорт** → EDL.
- `<название>_черновик.srt` — субтитры уже по черновику.
- `<название>_черновик_report.txt` — что вырезано и почему, с таймкодами исходника. Предложи
  пробежать глазами: оговорку от ошибки распознавания по тексту не отличить.

Итог в одну-две строки: «Было 12,4 мин, стало 10,8 мин, 31 кусок; из 168 фраз сценария найдено 166».
Если нашлось меньше 80% фраз, скажи, что сценарий, видимо, не совпадает с записью, и попроси проверить.
Если в строке JSON есть поле `update`, передай его пользователю одной фразой: вышла новая версия скилла.

## 4. Что честно сказать

- Если в последнем дубле ведущий начал фразу с середины, черновик тоже начнётся с середины.
- Куски речи не по сценарию скрипт оставляет и ставит на них маркер «Не по сценарию»: решать монтажёру.
- Бесплатная версия работает с одним исходником.
